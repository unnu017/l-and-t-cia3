This repository contains the JavaScript programs completed as part of my CIA Practical. The tasks demonstrate different Node.js concepts, including file handling, asynchronous operations, modules, and the use of `require()`.

## How to Run

Make sure Node.js is installed on your computer.

Run a task using:

```bash
node task1.js
```

You can replace `task1.js` with any other task filename.
